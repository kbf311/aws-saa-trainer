# AWS SAA-C03 Trainer

**AWS 認定ソリューションアーキテクト – アソシエイト（SAA-C03）** の試験対策を効率的に進めるための学習トレーニングアプリです。  
PC のブラウザ上で手軽に問題演習、解説確認、学習進捗や苦手分野の分析を行えます。

---

## 主な機能

- **実践的な問題演習**
  - 分野（ドメイン/カテゴリ）ごとの出題絞り込み
  - 問題数のカスタマイズ
  - 選択肢ごとの詳細な解説と正誤判定
- **学習ダッシュボード**
  - 全体の解答数・正答率の可視化
  - 分野別・カテゴリ別の習熟度グラフ
  - 直近の学習パフォーマンス確認
- **演習結果の振り返り（サマリー）**
  - セッション終了後のスコア表示
  - 間違えた問題の確認・解説再読

---

## 動作環境

- **OS**: Windows 10 / 11
- **Python**: Python 3.10 以上がインストールされていること
- **ブラウザ**: Google Chrome, Microsoft Edge など（最新版推奨）

---

## はじめかた（初回のみ）

アプリを使用する準備として、初回に 1 回だけセットアップを実行します。

1. 本フォルダ内にある **`run_setup.bat`** をダブルクリックして実行します。
2. 画面にインストールモードの選択肢が表示されます。
   ```text
   [1] requirements.txt (最新パッケージを推奨)
   [2] requirements-lock.txt (検証済みバージョン)
   ```
   **そのまま `Enter` キー**（または `1` を入力して Enter）を押すとインストールが始まります。
3. しばらく待って「セットアップ完了」と表示されたら、ウィンドウを閉じます。

---

## アプリの起動と終了

### 起動方法
1. 本フォルダ内にある **`run_app.bat`** をダブルクリックします。
2. コマンド画面が立ち上がり、自動的にブラウザが開いてアプリ画面（`http://localhost:8000`）が表示されます。

> **注意**: アプリ利用中は、黒いコマンド画面を**閉じずに開いたまま**にしてください。

### 終了方法
1. ブラウザを閉じます。
2. 起動している黒いコマンド画面で `Ctrl + C` を押すか、ウィンドウ右上の「×」ボタンで閉じてください。

---

## 学習の流れ

1. **出題設定を行う**
   - ダッシュボードの「演習を始める」または上部メニューの「出題設定」を開きます。
   - 演習したい問題数や出題範囲（全範囲、または特定のカテゴリ）を選択して開始します。
2. **問題を解く**
   - 問題文を読み、正解と思う選択肢を選んで解答します。
   - すぐに正誤判定と詳細な解説が確認できます。
3. **結果を確認する**
   - 全ての問題を解き終えると、サマリー画面で今回のスコアと各問題の振り返りが表示されます。
4. **ダッシュボードで進捗を確認する**
   - トップのダッシュボードに戻ると、これまでの累計成績やカテゴリごとの正答率が更新され、自分の弱点をひと目で把握できます。

---

## その他・便利な操作

- **問題データの手動同期**
  - 問題データが新しく追加・更新された場合、通常はアプリ起動時に自動で反映されます。
  - アプリを起動したまま即座に最新の問題データを反映したい場合は、**`run_sync_questions.bat`** をダブルクリックして実行してください。

## よくある質問 / トラブルシューティング

- **Q. ブラウザが自動で開かない**
  - 手動でブラウザを開き、アドレスバーに `http://localhost:8000` と入力してアクセスしてください。
- **Q. 画面が正しく表示されない / 起動しない**
  - 初回セットアップ（`run_setup.bat`）が正常に完了しているかご確認ください。
  - 別のアプリがポート `8000` を使用していないかご確認ください。
